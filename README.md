<h3 align="center">Right</h3>
Right is a distraction-free writing and reading tool powered by
AI, designed to enhance focus and productivity. It is completely free to use, with all data stored in your browser, ensuring privacy and convenience.
<hr/>

<h4>Credits and Attributions</h4>

1. Full credit for the design goes to the team behind <a href="https://github.com/hundredrabbits/Left" target="_blank">Left</a>, who generously allowed us to use and adapt their design.
2. Right is developed using open-source tools, with its AI capabilities powered by <a href="https://webllm.mlc.ai/" target="_blank">WebLLM</a> on the backend.
3. Currently AI capabilities are only supported in machines on browsers that support WebGPU. Please check <a href="https://github.com/mlc-ai/web-llm" target="_blank">WebLLM Github Repo</a> for more details.
4. For the PDF Reader functionalities, Right uses <a href="https://mozilla.github.io/pdf.js/" target="_blank">PDF.js</a> and <a href="https://mupdfjs.readthedocs.io/en/latest/#" target="_blank">MuPDF.js</a>.
